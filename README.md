# 软件开发需求提交系统

这是一个基于纯前端技术（HTML/CSS/JS）开发的轻量级需求提交系统。客户可以通过该系统填写需求详情、上传各类素材（图片、视频、文档等），系统会自动将所有内容打包成一个 ZIP 压缩包，方便开发人员对接。

## 功能特点

*   **纯前端运行**：无需后端服务器，直接在浏览器中运行，数据安全且保护隐私。
*   **一键打包**：自动生成包含需求文档（Word/Markdown）和分类整理好的素材文件夹的 ZIP 包。
*   **需求文档生成**：根据填写的表单自动生成格式化的需求说明书。
*   **离线可用**：所有依赖库已本地化，无网络环境也可使用。
*   **响应式设计**：简洁现代的 UI，适配不同屏幕尺寸。

## 目录结构

*   `client/index.html`: 系统入口文件。
*   `client/css/`: 样式文件目录。
*   `client/js/`: 逻辑脚本目录。
*   `client/lib/`: 第三方依赖库（JSZip, FileSaver, html-docx-js）。

## 如何使用

1.  **本地使用**：直接双击打开 `client/index.html` 即可。
2.  **部署上线**：请参考 `DEPLOY.md` 文件将系统部署到公网。

## 浏览器兼容性

支持现代浏览器（Chrome, Edge, Firefox, Safari 等）。由于使用了较新的 File API，不建议使用 IE 浏览器。
